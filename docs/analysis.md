## 3. 디자인 결정이 필요한 항목 (구현 보류)

게임의 손맛과 정체성을 바꾸는 항목입니다. 프로젝트 협업 원칙(질문 → 선택지 → 결정)에 따라
구현 전에 선택을 받습니다.

1. **정체성 정리(P0-2).** 성향 수치, 안전선 넘으면 "증발"하는 강화, 빨간·맑은 물약, 바람걸음·투지
   물약, 순간이동·귀환 주문서, 무게 50% 페널티의 조합과 표현은 1990년대 말 한국 MMORPG와 매우
   비슷합니다. 메커니즘은 유지하더라도 명칭과 문구를 고유하게 바꿀지 결정이 필요합니다.
2. **강화 실패(P1-8).** 선택지: (a) 현행 유지 (b) 실패 시 단계 하락 (c) 보호 주문서 추가.
3. **"느린 평타" 심화(P1-7).** 몬스터 준비 동작(0.5초)을 눈에 보이게 예고하고, 방패 막기나
   짧은 회피로 대응하게 할지 결정이 필요합니다.
4. **성향 활용(P1-9).** 지금은 가격 할인과 사망 페널티에만 쓰입니다. 퀘스트 분기나 NPC 반응까지 넓힐지
   정해야 합니다.
5. **UX(P2-11).** 튜토리얼 안내 위치와 지속 시간, 미니맵 또는 지역 지도 추가.
6. **경제(시뮬레이터 발견).** 오크 영지 Lv7(중급 장비)에서 빨간 물약(25닢)을 분당 8.1개 소비하는 데
   비해 수입은 분당 79닢입니다. 이 구간은 맑은 물약과 휴식 없이는 적자입니다. 의도된 압박인지 결정이
   필요합니다.

## 4. 볼륨 확장 계획

| 단계 | 내용 | 쓰는 도구 |
|---|---|---|
| 0 기반 (✅ 대부분 완료) | 소스 복원, 데이터 분리, 시뮬레이터, 메모리·번들, 저장 내보내기 | restore 도구, `npm test`, `npm run sim` |
| 1 2막 「성벽 너머」 Lv16→30 | 신규 지역 4곳(안개 늪, 무너진 감시탑, 얼어붙은 고개, 고대 수로), 지역당 몬스터 4~5종 + 네임드 1 | `codeart2d`(기존 팔레트 기반 PixelSpec, 변종은 팔레트 교체), `pixelfx` ice·lightning·shadow·weather·status, `level-designer`·`team-level` |
| 2 성장 축 | 직업 3개(검사·순례자·탐색자), 직업별 스킬 6~8개, 장비 접두사·세트, 재료 제작, 성향 분기 퀘스트 | `systems-designer`, `economy-designer`, `rpg`·`game-feel` 스킬, `balance-check` |
| 3 엔드게임 | 시드 기반 무작위 던전 「심연 회랑」, 강화판 보스 재도전, 주간 시드, 업적 | `procedural-gen` 스킬, 기존 시드 맵 빌더, 시뮬레이터로 층별 난이도 검증 |

콘텐츠 하나를 추가하는 흐름: GDD(`/design-system`) → `assets/data/*.json`에 수치 추가 →
codeart2d 스프라이트와 pixelfx 이펙트 → `node tools/pack-fx.mjs` → `npm test` → `npm run sim`.
