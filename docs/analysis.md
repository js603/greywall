## 3. 디자인 결정 (2026-11-11 확정)

| # | 항목 | 결정 | 근거 |
|---|---|---|---|
| 1 | 정체성(P0-2) | **현행 컨셉 유지.** 고전 국산 MMORPG 감성(성향, 강화, 물약·주문서, 무게)을 그대로 간다 | 사용자 결정. 단 실제 게임의 고유명사·아트·로고는 쓰지 않는다(현재도 고유 명칭) |
| 2 | 강화 실패(P1-8) | **현행 유지.** 안전선 초과 시 2/3 확률 소멸 | 사용자 결정 |
| 3 | 공격 예고·회피(P1-7) | **추가하지 않음.** 클릭 평타·자동 교전 유지 | 고전 컨셉과 맞지 않음. 손맛은 타격감(이펙트·사운드) 쪽에서 보강 |
| 4 | 성향 활용(P1-9) | **현행 유지**(사냥으로 상승, 사망 시 하락, 상점 할인). 2막에서 성향 조건 의뢰를 추가할 때 다시 본다 | PvP가 없어 지금은 진행도 지표 역할 |
| 5 | UX(P2-11) | **미니맵 추가**(우상단, N 키, 설정에서 끄기), **안내 문구는 클릭으로 닫기** | 지형·NPC·몬스터·출구 위치를 한눈에. 화면 비교로 확인 |
| 6 | 물약 경제 | **유지.** 오크 영지 초입의 적자는 물약 소모가 주된 지출인 고전 경제의 의도된 압박으로 본다. 2막은 2026-11-12 재측정: 사냥은 물약값, 의뢰는 장비값(`equipment-economy.md`) | 퀘스트 권장 레벨(6)과 장비 단계를 올리면 흑자 전환(Lv9 상급 장비: 소모 4.6병/분) |

## 4. 볼륨 확장 계획

| 단계 | 내용 | 쓰는 도구 |
|---|---|---|
| 0 기반 (✅ 대부분 완료) | 소스 복원, 데이터 분리, 시뮬레이터, 메모리·번들, 저장 내보내기 | restore 도구, `npm test`, `npm run sim` |
| 1 2막 「성벽 너머」 Lv16→30 (🟡 3/4: 안개 늪, 무너진 감시탑, 얼어붙은 고개 완료) | 신규 지역 4곳(안개 늪, 무너진 감시탑, 얼어붙은 고개, 고대 수로), 지역당 몬스터 4~5종 + 네임드 1 | `codeart2d`(기존 팔레트 기반 PixelSpec, 변종은 팔레트 교체), `pixelfx` ice·lightning·shadow·weather·status, `level-designer`·`team-level` |
| 2 성장 축 (🟡 일부) | ✅ 전직 3직업(기사·광전사·성기사, 직업별 스킬 2개, `class-change.md`), ✅ 대장간 재료 제작(`equipment-economy.md`). 남음: 장비 접두사·세트, 성향 분기 퀘스트 | `systems-designer`, `economy-designer`, `rpg`·`game-feel` 스킬, `balance-check` |
| 3 엔드게임 | 시드 기반 무작위 던전 「심연 회랑」, 강화판 보스 재도전, 주간 시드, 업적 | `procedural-gen` 스킬, 기존 시드 맵 빌더, 시뮬레이터로 층별 난이도 검증 |

콘텐츠 하나를 추가하는 흐름: GDD(`/design-system`) → `assets/data/*.json`에 수치 추가 →
codeart2d 스프라이트와 pixelfx 이펙트 → `node tools/pack-fx.mjs` → `npm test` → `npm run sim`.
