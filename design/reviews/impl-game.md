# 구현 리뷰 — 코어 루프 (game-designer, 2026-11-12)

30초 루프: 대상 클릭 → 자동 접근·평타, 플레이어 판단은 물약 타이밍·몇 마리를 끌지뿐(World.js:2057-2097).
5–15분 루프: 사냥 → 마을 보고 → 물약 보충. 레벨당 시간이 2분 → 33분으로 단조 증가, 새 동사 없음.

## 문제
- A [높음] 성향은 사실상 죽은 시스템: 모든 몬스터 lawful 양수, 감소는 사망 −30뿐, 효과는 할인 5/10%뿐, 조건으로 쓰는 곳 없음(World.js:251-255, 953, 1050).
- B [높음] 2막 페이스를 의뢰 XP가 떠받침(q_garrison 4200 = 구간의 30%), 사냥만으로는 레벨당 20–33분. 늪 Lv20 53.7분(반감 규칙).
- C [높음] MP 경제 막힘: 최대 MP 8+3(L−1), 5초당 1 회복, MP 물약 없음, 무게 50%↑면 MP도 정지 → 스킬은 풀 한 번 쓰는 소모품(World.js:2470-2471).
- D [높음] 무게: 2막 장비만으로 용량 70% 근처, 50%에서 HP·MP 회복 완전 정지(World.js:231-239, 2443-2471). 시뮬레이터 미반영.
- E [중간] 강화 +7 이후 보상(+1)이 위험(증발 2/3) 대비 너무 작아 아무도 안전선을 넘지 않음.
- F [중간] 사망 비용 가벼움(XP 8%, 아이템·동전 손실 없음).
- G [낮음] 낮·밤은 숲 묘지 스폰 외 장식.
- I [낮음] 직업 차이: 기사 XP +3%뿐(가치는 물약 절감), 광전사 +25%.

## 질문 후보
- 성향: **a 선택형 증감(의뢰·혼돈 경로)(추천)** / b 할인 위주 축소 / c 제거
- 2막 페이스: **a XP 곡선·HP 완화 + b 판단 요소 추가(추천)** / c 유지
- 강화 보상: **a +7↑ 단계 보너스 확대(추천)** / b 유지
- 사망 비용: **a 동전 손실(추천)** / b 성향 연동 드롭 / c 유지
- 무게: a 임계 상향 / **b 단계적 페널티(추천)** / c 유지
