# 강화 (Enhancement) — 구현 역문서화

## Overview

장착한 무기·갑옷·방패를 강화 주문서로 +1씩 올린다. 안전선(무기 +6, 방어구 +4)까지는 반드시 성공하고, 넘으면
1/3 확률로 성공하며 **실패하면 장비가 증발한다**. 최대 +10. 이 실패 규칙은 고전 MMORPG 감성의 핵심으로
유지한다(`docs/analysis.md` 결정 2). 2026-11-12 코드에서 역문서화.

## Player Fantasy

푸르게 빛나는 +7 무기를 위해 아끼던 검을 거는 도박. 안전선까지는 확실한 성장, 그 너머는 자랑거리.

## Detailed Rules

- **주문서:** 무기 강화 주문서(`scroll_ench_w`)는 장착 무기, 방어구 강화 주문서(`scroll_ench_a`)는 장착 갑옷, 갑옷이
  없으면 방패를 강화한다. 가방에서 주문서를 "읽기". 상점에서 팔지 않고 드롭·의뢰 보상으로만 얻는다.
- **판정:** 현재 수치 < 안전선이면 성공. 그 이상이면 성공 확률 1/3, 실패하면 장착 장비가 사라진다(수치 0, 칸 비움).
- **확인:** 안전선 이상에서 읽으면 확인 창이 뜬다.
- **효과:** 무기 +1당 피해 +1, 명중 +0.5(내림). 갑옷·방패 +1당 방어 +1.
- **판매가:** 가격 × 0.4 × (1 + 0.5 × 강화 수치).

## Formulas

- 성공 확률 P(n → n+1) = 1 (n < 안전선), 1/3 (n ≥ 안전선). 무기 +6 → +10 연속 성공 = (1/3)^4 ≈ 1.2%.
- 기댓값 예(하엘의 대검, 가격 3,200): +7 시도의 기대 손실 = 2/3 × 판매가 1,280 × (1 + 0.5×6) = 3,413닢 상당, 이득은 피해 +1(평균 피해의 약 7%).

## Edge Cases

- 장착한 장비가 없으면 주문서는 소모되지 않고 경고만 뜬다.
- +10에서는 더 강화하지 않는다(주문서 유지).
- 강화 직후 자동 저장하지 않으므로, 실패 후 강제 종료해 이전 저장으로 되돌릴 여지가 있다(구현 리뷰 질문 4).
- 갑옷을 벗고 있으면 방어구 주문서가 방패에 들어간다(의도 확인 대상).

## Dependencies

- 이 문서가 의존: 전투(강화가 피해·명중·방어에 더해짐), 아이템(`enchant` 종류), 드롭·의뢰 보상(주문서 공급), 저장.
- 이 문서에 의존: 장비와 경제(장비 가치·판매가), UI 확인 창(위험 고지).

## Tuning Knobs

| 값 | 위치 | 안전 범위 | 영향 |
|---|---|---|---|
| 안전선 | `constants.js` `ENCHANT_SAFE` | 무기 4–7, 방어구 3–5 | 확실한 성장 구간 |
| 위험 구간 성공률 1/3 | `World.enchant` | 0.25–0.5 | 도박의 매력 대 좌절 |
| +1당 효과 | `World` 피해·방어 계산 | 1–2 | 위험의 보상 |
| 주문서 드롭률 | `monsters.json` | 1–3% | 강화 속도 |

## Acceptance Criteria

1. `npm test`: 원본 동작 일치(`parity.test.js`). 강화 규칙을 바꾸면 전용 테스트를 추가하고 해시를 의도적으로 갱신.
2. 브라우저: 안전선 이상에서 확인 창, 실패 시 장비 증발 메시지.
