# 2막 2지역 — 무너진 감시탑 (Ruined Watchtower)

## Overview

안개 늪 북쪽 끝에서 이어지는 Lv 20–24 사냥터. 무너진 사각 성벽과 안뜰, 계단 위 본채가 있다.
성 밖 풀숲에는 검은 늑대, 안뜰에는 탈영 석궁병(원거리)·역병 수비병(독)·수비대 해골(방패 막기)이 있고,
본채 위에는 네임드 「타락한 감시대장 하엘」이 산다. 탁 트인 지형과 원거리 적이 늪과 다른 위협을 준다.

## Player Fantasy

버려진 국경 요새를 되찾는 기사. 성벽의 무너진 틈으로 숨어 들어가 석궁병의 사선을 피하고,
방패를 든 해골에게 강타로 균열을 낸다. 탑 꼭대기에서 옛 수비대장과의 결투.

## Detailed Rules

- **입구:** 안개 늪 북쪽 끝(31–32, 0) ↔ 감시탑 남쪽 끝(26–27, 49). 늪 둑길 중앙(36,22)에서 북쪽으로 갈라지는 길.
  남문 안쪽 (23,45)에 야영지와 암상인(`camps.md`, `alignment.md`).
- **지형:** 맵 54×50, 시드 77. 성벽 x 10–43, y 8–38. 벽 칸의 약 18%는 뚫린 틈, 8%는 잔해(통과 불가).
  남문 x 25–28. 본채 x 20–33, y 10–18은 한 층 높고 (26,19) 계단으로만 오른다.
- **사냥 구역 보장:** 몬스터 생성 반경 +1 안에는 나무를 심지 않는다(생성된 몬스터는 모두 걸어서 닿을 수 있어야 함).
- **몬스터:** 아래 표. 탈영 석궁병은 사거리 5에서 화살을 쏜다. 수비대 해골·하엘은 방패로 평타를 막는다(강타는 막지 못함).
- **의뢰 5개:** 성벽 너머의 감시탑(경비병), 버려진 휘장(교관), 역병의 성벽(사제), 남은 수비대(경비병), 타락한 감시대장(교관).

## Formulas

- 명중률 = clamp(0.8 + (명중 − 회피) × 0.03, 0.3, 0.95). 막기 확률은 방어측 `block`(평타에만 적용).
- 경험치 비율 r = XP ÷ HP: 늑대 0.76, 석궁병 0.89, 역병 0.72, 해골 0.78. 예: 석궁병 160 ÷ 180 ≈ 0.89
  (원거리라 잡기 까다로워 높게).
- 목표 물약 소모(빨간 물약 환산): 진입 장비 ≤ 12병/분, 지역 장비 4–8병/분. 레벨당 시간 20–30분.

## Edge Cases

- 석궁병이 벽 너머에서 쏘는 경우: 탄환은 시야(`lineOfSight`)가 끊기면 쏘지 않는다(기존 원거리 규칙).
- 본채 위 해골 2구와 하엘은 계단으로만 접근 가능. 계단 칸에서는 몬스터가 생성되지 않는다.
- Lv25 이상: 늑대·석궁병(20–21)은 경험치 절반(플레이어 ≥ 몬스터 + 5).
- 하엘 처치 후 재생성 900초.
- 측정 기준: 이 지역(Lv20–24)은 전직(Lv20) 이후 구간이므로 레벨당 시간 기준은 전직한 캐릭터로 잰다.

## Acceptance Criteria

1. `npm test`: 감시탑 맵 결정성, 늪↔감시탑 출구 왕복, **생성된 몬스터 전부 입구에서 도달 가능**, Lv20 사냥에서 레벨 상승.
2. `npm run sim`: 감시탑 장비 + 전직, Lv22–24에서 물약 4–8병/분(성기사 Lv22 9.5는 방어 모델 결정 대기), 레벨당 30분 이내.
3. 브라우저에서 늪 북쪽 출구 → 감시탑 이동, 성벽·본채·몬스터·미니맵 표시, 콘솔 오류 없음(스크린샷).
