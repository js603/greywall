# 장비 진행과 경제 (Equipment Progression & Economy)

## Overview

1막은 대장간에서 사는 장비와 네임드 드롭으로, 2막은 **대장간 제작(지역 재료 + 수수료)**과 **네임드 의뢰 보상 장비**로
장비를 갖춘다. 돈의 흐름은 둘로 나뉜다: **사냥은 물약값을 벌고, 의뢰는 장비값을 번다.** 지역 장비를 갖춘 전직
캐릭터는 사냥에서 물약값을 내고도 동전이 남고(순이익 ≥ 0), 진입 직후 1단계 낮은 장비로는 적자다(고전 MMORPG의
"장비를 맞춰야 사냥이 된다"는 압박). 모든 값은 `assets/data/{items,recipes,shops,monsters,quests}.json`.

## Player Fantasy

새 지역에 들어서면 물약이 빠르게 줄어든다. 그 지역 몬스터의 재료를 모아 대장장이 고른에게 가져가면 그 땅을 버틸
갑옷이 나온다. 네임드를 쓰러뜨린 의뢰의 보상은 그 지역의 무기·장신구다. 운 좋은 희귀 드롭은 지름길이다.

## Detailed Rules

- **획득 경로 (2막):**

| 지역 | 장비 | 경로 |
|---|---|---|
| 안개 늪 | 안개서린 검(Lv16) | 제작: 안개 정수 12, 독샘 8, 1,600닢 · 안개 망령 0.6% · 베일라 25% |
| | 늪비늘 갑옷(Lv17) | 제작: 늪 트롤 가죽 10, 늪 진흙 12, 1,500닢 · 늪 트롤 0.8% |
| | 안개 마녀의 부적 | 의뢰 「안개 마녀 베일라」 보상 · 베일라 40% |
| 무너진 감시탑 | 감시탑 방패(Lv20) | 제작: 녹슨 휘장 10, 검은 늑대 가죽 10, 1,300닢 · 석궁병 0.8% |
| | 수비대 사슬갑옷(Lv21) | 제작: 뼛가루 15, 역병 누더기 10, 2,600닢 · 수비대 해골 0.7% · 하엘 25% |
| | 하엘의 대검(Lv21) | 의뢰 「타락한 감시대장」 보상 · 하엘 30% |
| 얼어붙은 고개 | 설인 털갑옷(Lv25) | 제작: 설인 털 10, 흰 늑대 가죽 10, 3,800닢 · 설인 0.6% |
| | 서리 반지 | 제작: 서리 파편 12, 골렘의 심장석 6, 3,000닢 · 정령 0.4% · 하임 30% |
| | 빙하의 대검(Lv25) | 의뢰 「빙하 거인 하임」 보상 · 하임 30% |

- **제작:** 대장간 대화 → 거래하기 → `제작` 탭. 재료(가진 수/필요 수)와 수수료가 보이고, 조건이 맞으면 버튼이 켜진다.
  필요 레벨 미달·재료 부족·동전 부족이면 꺼진다. 제작하면 재료와 동전을 내고 장비 1개를 받는다(강화 수치 0).
- **방패는 모든 직업이 쓸 수 있다**(2026-11-12 결정). 직업별 장비 제한은 없다.
- **경제 목표**(빨간 물약 25닢 환산, `npm run sim`의 Net/min = 동전 + 주운 물건 판매가 − 물약값):
  - 지역 장비 + 전직: 순이익 ≥ 0(기사·광전사는 +30 이상).
  - 진입 장비(이전 지역 장비): 적자 허용(물약 압박), 단 사망 0.
- **의뢰 동전 ≈ 지역 제작비:** 늪 의뢰 동전 합 2,850 / 제작 3,100, 감시탑 4,000+ / 3,900, 고개 7,200 / 6,800.

## Formulas

- 제작 재료 수 = 목표 사냥 시간 × 분당 처치 × 드롭률. 예: 늪비늘 갑옷 트롤 가죽 10개 ÷ 50% = 트롤 20마리
  (늪 남서쪽 트롤 구역 15–20분).
- 수수료 ≈ 장비 가격 × 0.7(늪비늘 2,200 → 1,500, 설인 털갑옷 5,600 → 3,800). 판매가(가격 × 0.4)보다 높아 제작-판매로 돈을 벌 수 없다.
- 2막 일반 몬스터 동전 = 기존 × 1.3(2026-11-12 조정). 예: 수비대 해골 30–60 → 39–78.
- 순이익/분 = 동전/분 + 판매가/분 − 물약/분 × 25.

측정(`npm run sim`, 20분 × 3시드, `design/balance/sim-report.md`):

| 조건 | 순이익/분 | 물약/분 |
|---|---|---|
| 늪 Lv16, 1막 최고 장비(진입) | −146 | 10.7 |
| 늪 Lv18, 늪 제작 장비 | +11 | 5.0 |
| 감시탑 Lv22, 1막 최고 장비 | −163 | 13.1 |
| 감시탑 Lv22, 제작 장비, 기사·광전사·성기사 | +75 · +67 · −24 | 4.8 · 5.9 · 9.5 |
| 감시탑 Lv24, 하엘의 대검, 세 직업 | +187 · +46 · +20 | 3.9 · 7.3 · 8.1 |
| 고개 Lv24, 감시탑 장비, 세 직업 | +56 · +33 · −37 | 4.6 · 7.3 · 8.2 |
| 고개 Lv27, 고개 장비, 세 직업 | +68 · +134 · +62 | 4.1 · 4.0 · 6.3 |

## Edge Cases

- 가방이 가득 차 제작품을 못 받으면 재료를 되돌리고 동전은 내지 않는다.
- 같은 재료를 의뢰(전직의 시험: 트롤 가죽 5, 안개 정수 5)와 제작이 함께 쓴다. 의뢰가 먼저 가져간다(플레이어 선택).
- 의뢰 보상 장비는 희귀 드롭과 중복될 수 있다. 남는 것은 판다(판매가 = 가격 × 0.4).
- 성기사는 감시탑 Lv22·고개 Lv24에서 소폭 적자다(물약 8–9.5병/분). 방어 모델 결정(구현 리뷰 질문)에서 다시 본다.
- 고개 Lv27은 빙하의 대검 없이(하임 처치 전) 측정한다. 처음 측정에서 기사·성기사가 레벨당 36–37분이라 고개 일반 몬스터 XP를
  4–6% 올렸다(눈 늑대 220, 정령 250, 설인 295, 골렘 345) → 34.5·27.0·35.2분.

## Dependencies

- 이 문서가 의존: 상점(`World.buy/sell/priceOf`), 드롭(`monsters.json` drops), 의뢰 보상(`quests.json`),
  무게(`World.capacity`), 2막 지역 문서 3개(재료 출처).
- 이 문서에 의존: 2막 4지역(고대 수로)의 장비 단계, 강화(장비 가치), 밸런스 시뮬레이터 장비 조합(`tools/balance-sim.mjs`).

## Tuning Knobs

| 값 | 위치 | 안전 범위 | 영향 |
|---|---|---|---|
| 재료 수 | `recipes.json` mats | 8–15 | 장비 1개당 사냥 시간(목표 15–30분) |
| 수수료 | `recipes.json` coins | 가격의 0.5–0.9 | 의뢰 동전의 쓰임 |
| 2막 동전 드롭 | `monsters.json` coins | 기존 ×1.0–1.6 | 사냥 순이익 |
| 재료 드롭률 | `monsters.json` drops | 0.3–0.6 | 제작 속도 |
| 희귀 장비 드롭률 | 같은 곳 | 0.3–1% | 지름길 빈도 |

## Acceptance Criteria

1. `npm test`(`tests/craft.test.js`): 레시피 → 실재 아이템·재료·상점, 제작 시 재료·동전 차감과 장비 지급, 재료·동전·레벨 부족과 다른 상점 거부.
2. `npm run sim`: 지역 장비 + 전직에서 기사·광전사 순이익 ≥ 0, 사망 0.
3. 브라우저: 대장간 `제작` 탭, 재료 개수 표시, 제작 성공, 콘솔 오류 없음.
